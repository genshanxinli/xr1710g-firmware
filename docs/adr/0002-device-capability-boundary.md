# ADR-0002: 设备能力全集为集成边界，运营商功能默认放弃

**Status**: accepted

**2026-08-16**。上下文："集成最多（设备本身的功能）"存在歧义——曾有两种解读：硬件能力全集 vs 保留/复刻 ISP 原厂功能。决定："设备本身的功能"的规范定义 = **设备能力全集**（三频射频、6GHz、EHT320、双万兆口、硬件卸载、LED/按键等全部启用且可配置），并据此锁定 v1 验收：三频 AP + 6GHz 无线回程、双万兆灵活 WAN/LAN、SQM + WireGuard/OpenVPN、DNS 过滤 + LED/按键自定义、Docker/应用中心（后置）、NPU 全功能（含 AP/桥接专项与实机盘点闭环）。

**Considered Options**：
- 保留/复刻运营商功能（云 Mesh、家长控制、管理通道）——本机是 ISP 淘汰机，云端通道已死，社区口碑在硬件能力而非运营商功能，且复刻成本高，否决
- 两者都要——冲突时难以取舍且拖慢前沿跟踪，否决

**Consequences**：
- 明确收入 CONTEXT.md 术语表（设备能力全集 / 运营商功能 / NPU 全功能）
- 个别运营商功能若未来被证明值得复刻，须再走一次 ADR，默认不复刻
- 6GHz 相关功能完整交付，但中国大陆使用属无授权（监管自担），需在 README 与发布帖明示合规边界
