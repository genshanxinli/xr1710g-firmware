# ADR-0001: 固件基底采用完全自主分支 + 事件驱动发布

**Status**: accepted

**2026-08-16**。上下文：XR1710G 处于 OpenWrt 主线收尾窗口（PR #22397 open、已实机验证），项目定位"公开社区固件 + 情报体系"、"前沿跟踪第一"。决定：固件基底 = 基于 OpenWrt main 的**完全自主分支**（AI 每日自动合入 upstream main，含 mt76/hostapd；冲突自动处理或上报；补丁分"设备适配层 / 激进调优层"两层）；发布 = 公开 GitHub 仓库（GPL-2.0-or-later）+ **事件驱动 + 每夜保底** Release；引导链 = 实机全部走 YYH 路线（见 ADR-0002 关联），upstream chainloader 为文档备选；发布帖草稿由 AI 生成、人工确认发布。

**Considered Options**：
- (a) 官方 OpenWrt 主干 + 薄层自研（推荐过两次，被用户否决——要求完全掌控发行）
- (b) iStoreOS 分叉（官方硬件列表未收录此机，上游同步滞后，否决）
- (c) 锁定社区已验证 commit 基线（与"前沿跟踪第一"冲突，否决）
- 完全自主分支的持续 rebase 负担原本是人工不可承受的，但由 AI 每日同步循环承担后成立——这是本项目"全 AI 驱动"的核心红利。

**Consequences**：
- 持续 rebase 债转嫁给 AI 每日循环；冲突无法自动解决时上报人工（属人类最小集边缘）
- U-Boot 维护面依赖社区 YYH2913（单点）：备份其固件镜像 + 串口回刷路径入救砖 SOP 兜底
- 固件镜像与社区生态保持兼容（同一 ITB / UBI 2.0 布局），分叉产物可被两种引导路线消费
- 可复现构建（公开脚本/configs）同时满足 GPL 合规义务
